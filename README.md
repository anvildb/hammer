# Hammer — downloads

Hammer is the desktop client for [Anvil DB](https://anvildb.com): the Hammer
admin UI as an installable app for macOS and Windows.

This repository holds the **releases**. Each one carries signed installers:

- **macOS** — [Hammer-macos.dmg](https://github.com/anvildb/hammer/releases/latest/download/Hammer-macos.dmg) (universal: Intel and Apple Silicon)
- **Windows** — [Hammer-windows-x64.msi](https://github.com/anvildb/hammer/releases/latest/download/Hammer-windows-x64.msi)

Those links always point at the newest release; the versioned installers for
each release are on its page under [Releases](https://github.com/anvildb/hammer/releases).

On first launch, point it at your Anvil DB server (it defaults to
`http://localhost:7474`; the login screen's server picker handles remote
instances). Documentation: [anvildb.com](https://anvildb.com).
